---
name: Lab style like dev books
description: Hands-on labs should be written like development books - generic instructions readers follow on their own, not tied to this repo's directory
type: feedback
---

실습 섹션은 개발서적 스타일로 작성할 것. "이 프로젝트의 labs/ 디렉토리에..." 같은 레포 종속 표현 대신, 독자가 자기 환경에서 따라할 수 있는 범용적 설명으로 작성.

**Why:** 사용자가 직접 따라하며 배우는 스타일 선호. 학습자료는 독립적인 서적처럼 읽혀야 함.
**How to apply:** "프로젝트 루트에 labs/ch07 디렉토리를 만들어" 대신 "작업 디렉토리를 만들고" 식으로. 경로는 상대적/범용적으로.
